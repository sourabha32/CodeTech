## CODTECH Internship – Task 2: REST API Client

This is a Java console application that calls the public Open-Meteo REST API to fetch current weather data for a selected city and prints it in a structured format.

### Requirements

- Java 11 or higher
- Maven 3.x

### Build

```bash
mvn clean compile
```

### Run

```bash
mvn exec:java
```

When the program starts, choose one of the listed cities to see its current weather report.
